# foursqr voor Home Assistant.

Add-onrepository van foursqr. Hiermee zet je foursqr op je Raspberry Pi met Home Assistant.

Uitleg en installatie: https://knx.foursqr.ai/raspberry-pi

## Toevoegen aan Home Assistant.

Instellingen > Add-ons > Add-on store > ⋮ > Repositories, plak `https://github.com/Foursqr/foursqr-hub` en kies
Toevoegen. Daarna staat foursqr in de winkel.

Deze repository bevat alleen de beschrijving van de add-on. De container komt uit
`ghcr.io/foursqr/foursqr-addon-<arch>`.
